KETCHUP kinetic parameter estimation, wrapped as a process-bigraph Step

KETCHUP (Maranas group) fits the kinetic parameters of a metabolic network by solving one IPOPT nonlinear program so the model reproduces measured steady-state fluxes and metabolite concentrations. KetchupEstimator bridges the genuine ktools solver — its update() builds the real Pyomo model and calls IPOPT; nothing here is reimplemented or mocked.

Below: the real solver run on two K-FIT E. coli models — k-ecoli74 and k-ecoli307 — plus a multistart re-fit driven through the Step's seed input port.

Solves are bounded (max_iter / max_cpu_time) so the demo finishes in ~56s total — reported solutions are genuine but partial, and each run's IPOPT termination condition is shown as-is. The objective rises while primal infeasibility falls: IPOPT is driving a random initial guess onto the steady-state manifold (satisfying every rate-law constraint), trading apparent error for feasibility. Charts show only normal iterations (restoration-phase sub-iterations are excluded). Use the vendored ipopt.opt (max_iter 5000) for full convergence.
